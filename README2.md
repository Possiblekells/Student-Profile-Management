# Student Profile Management System

## Project Description

Student Profile Management System is a React application designed to display and manage student profile information in an organised and user-friendly interface.

The application displays student details such as names, email addresses, departments, academic levels, profile pictures and student statuses.

## Features

- Display student profiles.
- Show student names and email addresses.
- Display departments and academic levels.
- Show student status (Active, Pending and Inactive).
- View Profile buttons with interactive alerts.
- Responsive layout for desktop and mobile devices.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate into the project folder:

```bash
cd Student-Profile
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
